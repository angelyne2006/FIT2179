# FIT2179

When Rain Becomes a Disaster, an interactive data visualisation of Malaysia’s 2024 to 2025 flood season. It covers where the heaviest rain fell, how many people were evacuated and how much the floods cost each state. Built with Vega-Lite, HTML and CSS, using data from HDX, DOSM and ReliefWeb. Created by Angelyne Chai Zi Xuan, May 2026 for Assignment 2 FIT2179 Semester 1 2026.
